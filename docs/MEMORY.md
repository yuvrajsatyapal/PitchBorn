# Football Memory

Important moments are detected as they happen, scored 0–100 from context, stored as structured data and presented later. Code: `src/engine/memory/`.

## Data
`state.user.memories: Memory[]` (types in `engine/types.ts`). A memory stores ids and numbers only — kind, season/turn/age, club, opponent, competition and stage, fixture id, minute, score, outcome, venue, rival, manager, transfer, trophy, tags, a small `data` block and the `factors` its importance was built from. Titles and sentences are generated by `describe.ts` (wording variants chosen from the memory id, so a memory always reads the same).

## Scoring (`score.ts`)
Context points are summed, then `importance = 100·(1 − e^(−raw/34))`. Tiers: Iconic ≥ 75, Major 55–74, Notable 35–54. Match moments only count once there is something to remember (a debut, goals, winner, comeback, upset), then context adds: competition/stage (finals, knockouts, continental/international weigh more), rivalry (up to +24), minute (80'+ and 90'+ winners), age (≤21, ≥34), opponent standing, thrillers. Multipliers: repeating a kind of moment is worth less (down to ×0.55), and lower-reputation players get a small underdog bump. Calibration: the age-19 derby brace with a 90+3 winner in a 3–2 win scores ≈ 94 (`tests/memory.test.ts`). Stored if ≥ 40 (debuts/firsts always). At most 300 are kept; ≥ 70 never dropped.

## Detection (`detect.ts`)
- Matches: `detectMatchMemory` after every user match (one memory per match; strongest aspect names it, the rest become tags/points). `detectInjuryComeback` for the first game back from a 12+ week injury.
- Honours: trophies (first league title, continental, international), awards, records, promotion/relegation.
- Career: transfers (big move, controversial, return to a former club, financial exit), rejected offers, contract disputes, captaincy, manager conflict (once per manager), defining decisions, major injuries, retirement and final match.

## Rivalries (`rivalry.ts`, `src/data/rivalries.json`)
Editorial strengths for ~120 well-known derbies, 0.4 for clubs in the same city, plus heat the user's own moments create (`rivalHeat`, capped +0.35).

## Recall (`recall.ts`)
Once a week (after the new turn begins) `refreshRecall` picks at most one memory worth resurfacing and stores it as `user.vault`; it is shown as the dashboard's **From the vault** card, as **Memory lane** on the match page, and sometimes as a "memory" news item. Candidates:
- **Anniversaries** — same week, 1/5/10/15/20 seasons on, memories ≥ 55 only ("Five years since your first professional goal").
- **This week's match** — facing the club where your career began, a former club or a club where something big happened, an opponent you have history with, a ground where you made your mark, or a manager you fell out with.
Weight = importance × reason × freshness; below 48 nothing shows. Restraint: 3 weeks between recalls (opponent stories may break it), 6 weeks between news items, a memory is not repeated within 52 weeks and decays with each showing. Retirement/final-match memories are never recalled mid-career. All text is second person ("you"), generated from the stored data.

## Old saves
Schema v3 → v4 rebuilds what older saves recorded (debut, firsts, trophies, awards, moves, promotions, retirement), flagged `backfilled`; minutes and scorelines can't be recovered.
